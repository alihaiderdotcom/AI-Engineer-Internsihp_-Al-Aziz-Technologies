# Week 1, Day 5 - Weekly Project & Revision

**Focus:** Combine Python fundamentals, data structures, functions, modules, OOP, files, logging, and NumPy.

## Weekly Project: Internship Contact Manager

This console application stores internship contacts in a JSON file. It demonstrates:

- Variables, strings, numbers, and input validation
- Lists and dictionaries
- Conditions and loops
- Functions and modules
- A `Contact` class with methods
- JSON file persistence
- Exception handling and logging
- NumPy statistics for contact scores

## Run

```bash
python3 contact_manager.py
```

The program creates `contacts.json` and `contact_manager.log` during execution. These generated files are ignored by Git.
